# Refuge v2 performance baseline

The v2 benchmark fixture is generated by `scripts/benchmark.sh`. It creates
multiple repositories, publishes a checkpoint followed by incremental pushes,
adds a content-addressed LFS object to the first repository, and measures
status, catalog listing, idempotent backup, deep verification, clean restore,
target bytes, and file count.

Run a release build on the target machine and preserve its CSV-style output:

```sh
cargo build --release
scripts/benchmark.sh target/release/refuge
```

No machine-specific measurements are committed from this development
environment. The required real Obsidian validation remains: first checkpoint,
ten ordinary pushes, clean-machine restore, and `snapshots verify`. Repository
contents must not be recorded in this document.
